# WellMax trilingual coverage audit — 2026-08-21

Target locales: English (root), Portuguese (`/pt/`), Spanish (`/es/`).

## Findings before this change
- Spanish contained only the homepage.
- Portuguese had strong partial coverage but lacked several hubs, biomarkers, and many peptide profiles.
- Supplements existed primarily in Portuguese.
- Several peptide pages existed only in English while AOD-9604, Epitalon, GLOW/KLOW existed only in Portuguese.
- The sitemap still referenced the legacy `pepeducation` path and did not enumerate the full localized inventory.

## Remediation
This change creates localized counterparts for the public hubs, biomarker profiles, peptide profiles, and supplement profiles that were missing a locale. New pages include canonical and `hreflang` links for EN/PT/ES and preserve educational / non-medical framing.

The sitemap is regenerated to use the WellMax production path and include the three locale variants for the public inventory.
